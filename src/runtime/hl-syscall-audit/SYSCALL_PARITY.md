# Production syscall parity

Generated by `cargo run -p hl-syscall-audit`. Do not edit manually.

This compares the production retained-C x86-64-to-AArch64 number map with the typed Rust router table. The C source is authoritative for production execution; the Rust table is retained domain infrastructure, not a selectable guest executor. `syscall-inventory.tsv` retains independent ARM64 and x86-64 status so an ISA-only legacy syscall cannot promote a different canonical operation.

| Status | Count | Meaning |
|---|---:|---|
| supported | 256 | Production C mapping agrees with the typed route on every applicable guest ISA |
| router-domain-only | 33 | Typed legacy route has no production C mapping |
| missing | 72 | Missing or number/name-divergent in the typed route on at least one applicable ISA |
