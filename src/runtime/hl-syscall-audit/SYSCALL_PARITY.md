# Production syscall parity

Generated by `cargo run -p hl-syscall-audit`. Do not edit manually.

This compares the retained C x86-64-to-AArch64 number oracle with the typed Rust router table and the syscalls explicitly wired by production `GuestExecutor`. Typed domain implementation is not counted as production support. `syscall-inventory.tsv` retains independent ARM64 and x86-64 status so an ISA-only legacy syscall cannot promote a different canonical operation.
