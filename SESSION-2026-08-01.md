# Session 2026-08-01 — where the work stands

One day, a fleet of agents, GL/Vulkan/CUDA through the native macOS surface with
Chrome as the final verification. This is the index: what changed, what is
measured, and where to continue. Each area has its own handoff document; this
file points at them rather than repeating them.

## The headline

**Chrome renders.** It had never opened a window on this stack before today. A
native toplevel appears, presents frames, reports every feature accelerated on
`chrome://gpu`, and draws real text.

**Vulkan applications present.** Also a first: `vkwin` and `vkcube` reach the
window server through the Metal presenter.

Neither is finished. Chrome still composites large black regions, and a user
running it interactively saw repeated segfaults that no harness has reproduced.

## What was fixed, with the mechanism

| commit | defect |
|---|---|
| `05a755cbf` | `GL_BGRA_EXT` was not colour-renderable while the driver advertised the extension whose defining property is that spelling. Chrome's raster tiles were framebuffer-incomplete. |
| `58d5c7b9f` | `glVertexAttribIPointer` discarded the integer flag at the entry point, so attributes lowered to `Float32x2` while Chrome's shader required `Uint32x2`. wgpu refused the pipeline; the refusal rolled back Chrome's entire 1121-command startup batch, and every later frame referenced resources that had evaporated. **This is why Chrome had no window.** Broken since 2026-07-23, no test drove the path. |
| `66343a8ee` | `create_swapchain` omitted `texture_usage::PRESENT`, so IOSurface backing was refused and the producer skipped the frame down a silent `continue` while the guest saw `VK_SUCCESS`. **This is why no Vulkan client ever presented.** The comment beside the omission already named the correct set. |
| `bf864564f` | `has_content()` answers "may this be shown"; three call sites were asking whether content had been *committed*. A GPU token is a promise to present, so a toplevel counted as mapped before its first commit and the not-mapped-to-mapped transition never fired. |
| `dcaea6e2e`, `7e7dbbf62` | Four Vulkan shim sites dropped a recorded refusal (`let _ =` where siblings latched); swapchain images now derive usage from one source; `vkCmdFillBuffer` honoured `VK_WHOLE_SIZE` rounding; vertex layouts indexed by binding number. |
| `d471e287a` | 636 block-compressed blit cases were advertised and then refused at record time. Un-advertised honestly, verified with a null control and a positive control. |

## Where to continue — by document

- `src/surface/hl-gl/` blank content — **the live defect, and it has at least
  three distinct causes**, which is why a single-cause fix would leave the
  symptom intact. Measured with repeats-intact tracing: a texture never minted
  (107, 138); one minted under a *stale generation* (106 holds `[335]` while the
  sampler asks 364); and one sampled *before* the render and rescued only by a
  previous frame's history (108, `fbo_order=[64, 63]` with `render_target_of=[63]`).
  Registration itself is *not* gated — 17 targets minted across 11 names in one
  run. Fail-first signal is recorded precisely: 107, 138 and 106 must resolve
  while 108 still does. Evidence in `e2e/husklet/apps/browsers/README.md`; the
  diagnostic and two *indicted* changes are preserved unmerged in worktree
  `/Users/x/dd/hl-work/tex-fix` at `32011b0b`, marked not-for-merge.
- `src/gpu/hl-gpu-wgpu/SUBMIT_PROPAGATION.md` — 54 `?` operators in the submit
  loop each abort the whole command buffer, and the error returns before
  `submit_encoded` so already-encoded work is dropped. This is the amplification
  that turned one refused pipeline into a dead browser. Fully specified, unbuilt.
- `src/surface/hl-vulkan/BLIT_HANDOFF.md` — 3D blits (352 cases, an
  unannounceable hole: no query lets a driver decline them) and integer blits
  (100 cases; wgpu has no native blit, it samples through a draw). Oracle and
  recorder layers landed; executor layer remains.
- `src/gpu/hl-gpu/HANDOFF.md` — CUDA cross-connection buffer sharing. Export
  registry and access gate landed; protocol commands and executor wiring remain.
  0 of 23 CUDA graphics-interop entry points exist, so no CUDA renderer can
  present at all.
- `e2e/husklet/apps/gl-diff/README.md` — the differential harness, its two blind
  spots (no presentation, and **no frame boundary**), and why its three
  render-to-texture cases pass while Chrome's equivalent fails.
- `e2e/husklet/apps/gl-chrome-patterns/` — windowed mini-clients, seconds not
  minutes. **A minimal client constructing the exact shape of the live defect
  PASSES**: FBO colour attachment sampled in the same frame, across real
  `eglSwapBuffers` boundaries, on `(gl_tex, generation)` pairs minted in the
  sampling frame. Nothing samples black. So whatever Chrome does additionally is
  the trigger, and narrowing that is the next move — the minimal shape is
  exonerated. `int_attrib` and `bgra_tile` confirm two of today's fixes by
  running clients.

## Instrumentation added, because it was the bottleneck

More of this session went on instruments than on driver code. Four defects all
presented identically as "Chrome shows nothing"; localising cost hours, fixing
cost minutes.

- `hl-log` structured events (`28eef6f7f`): typed fields, one JSON record per
  line, call-site provenance, unmaskable verdict class. Consumer guide in the
  RUNBOOK.
- Deferral fates with per-call-site reasons — a commit parked forever was
  previously indistinguishable from one never made.
- `latch()` as the choke point for every Vulkan record-time refusal.
- Host tag opening (`hostlog`), and an announce when a tag list opens nothing.

## Rules this session paid for

In `AGENTS.md`. The ones that cost the most:

- A pass condition satisfied by the absence of the measurement is not one.
- A harness that does not enable its diagnostic measures its own configuration.
- A safeguard is only as wide as the build you run it against — and
  `--workspace` is not the whole tree; five shim crates sit outside it.
- A mute instrument is worse than a missing one; a silent control proves nothing
  until the channel is shown carrying a message you know was sent.
- A comment asserting a capability is a hypothesis. Three load-bearing false
  comments were found today; one sat on the line that broke every Vulkan window.
- A ratchet reports regression, not correctness.
- A diagnostic gated on the symptom cannot confirm its own repair. One trace
  produced zero lines while nine targets were minted, because it was gated on
  the very condition it existed to investigate.

## Known-open, briefly

- Chrome segfaults, unreproduced outside the user's workspace. Note they ran

- A texture uploaded from client memory reads back as ANGLE's extension string
  (`L_OE…`). Nine rounds, still a distinct defect.
- Frame-time drift ~1.27 late/early over two minutes, mechanism unresolved; both
